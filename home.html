百度网盘直链解析助手

高速直链解析 · 推荐 Motrix / Aria2 推送 · 支持浏览器直链 / cURL / IDM

使用须知与规范：
解析历史 0
  • 必须先将资源转存到自己的网盘再创建分享；仅解析根目录文件，子目录会被自动忽略。
  • 百度网盘直链强制校验 User-Agent: netdisk，推荐优先使用 Motrix / Aria2 一键推送下载；普通浏览器直接下载需安装 UA 切换插件，否则将报错 sign error (31362)。
  • 服务端限制单个网盘账号每小时约 5 个文件（基于网盘 UID 限制，使用代理 IP 无法绕过）；如需继续下载请转存至小号并点击右上角「重置解析凭证」。
  • 在「打开」按钮上点击鼠标右键可随时配置本地/远程 Motrix 或 Aria2 RPC 连接，也可在其中管理解析凭证。
